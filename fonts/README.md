# Self-hosted fonts

Latin-subset WOFF2 files from the Fontsource packages (`@fontsource/ibm-plex-sans`, `@fontsource/ibm-plex-mono`, `@fontsource/space-grotesk`, version 5.x), all under the SIL Open Font License 1.1. Each license text is in this folder. The fonts keep their copyright holders (IBM Corp.; The Space Grotesk Project Authors); the repository's MIT license does not cover them.
